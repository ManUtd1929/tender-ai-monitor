# Tender AI Monitor

Система автоматического мониторинга тендеров на сайте государственных закупок Армении:

https://gnumner.minfin.am/

## Цель

Автоматически находить новые тендеры, связанные с логистикой, перевозками и релевантными закупками, анализировать их и отправлять краткую информацию ответственным сотрудникам через Telegram.

## Планируемый процесс

1. Получение новых объявлений с сайта.
2. Определение новых и уже обработанных тендеров.
3. Первичная фильтрация по тематике.
4. Скачивание тендерной документации.
5. Извлечение текста из PDF/DOCX.
6. Анализ тендера с помощью ИИ.
7. Формирование краткого структурированного описания.
8. Сохранение результата в базе данных.
9. Отправка релевантных тендеров в Telegram.
10. Автоматический запуск системы по расписанию.

## Основные компоненты

* `src/scraper` — получение данных с сайта закупок.
* `src/parser` — обработка PDF, DOCX и других документов.
* `src/filters` — первичная фильтрация тендеров.
* `src/ai` — AI-анализ тендерной документации.
* `src/database` — работа с базой данных.
* `src/telegram` — отправка уведомлений в Telegram.
* `config` — настройки системы.
* `data` — рабочие данные.
* `tests` — тесты.
* `logs` — журналы работы программы.

## Текущий статус

Проект находится на этапе первоначальной настройки и исследования источника данных.
